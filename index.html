GST Goods & Services Tax

Intra-state sale

GST = CGST + SGST
CGST = SGST = ½ × GST rate
e.g. GST 12% → CGST 6% + SGST 6%

Inter-state sale

IGST = full GST rate (no CGST / SGST split)

Tax paid to Government

Tax = Output GST − Input GST
Input GST = GST paid on purchases (credit)
Key: GST is charged on the discounted price, never on M.P.

Discount chain

Discount = d% of M.P.
S.P. = M.P. − Discount
Price incl. GST = S.P. + GST on S.P.

Shares & Dividends Investment, FV, MV, Return

Values of a share

F.V. = Face/Nominal value (usually ₹100)
M.V. = Market value
Premium → M.V. > F.V. · Discount → M.V. < F.V.

Number of shares

n = InvestmentM.V. = Annual incomeDividend per share

Dividend & income

Dividend is always on F.V.
Annual income = Rate × F.V. × n100
“15% ₹100 shares at ₹145” → income ₹15 on ₹100, not ₹145

Return %

Return% = Annual incomeInvestment × 100
Return% = Rate × F.V.M.V.

Heights & Distances Angles of elevation & depression

The workhorse — tan θ

tan θ = OppositeAdjacent = HeightHorizontal distance
sin/cos used when the slant side is involved

Elevation vs depression

Object above eye-level → angle of elevation ↑
Object below eye-level → angle of depression ↓
Depression from A to B = elevation from B to A (alternate angles)

Two-position trick

h = d · tan θ₁ · tan θ₂tan θ₁ − tan θ₂
d = distance walked between the two observation points

Shadow fact

Elevation 30° → shadow = √3 × height
Elevation 45° → shadow = height

Graphical Representation Histograms & Ogives

Histogram rules

Bars touching · x-axis = class intervals · height = frequency
Unequal widths → use frequency density (height = f ÷ width)

Ogive (cumulative curve)

Plot (upper class limit, cf) points · join with smooth curve
Start at (lower limit of 1st class, 0)

Read from the ogive

StatisticRead x at cf =
MedianN/2
Lower quartile Q₁N/4
Upper quartile Q₃3N/4
e.g. N=120 → read at 60, 30, 90

Mode from histogram

Join top corners of modal bar to opposite corners of neighbour bars → x-value where lines cross
Modal class = class with the tallest bar

Measures of Central Tendency Mean · Median · Quartiles · Mode

Mean

Direct: x̄ = ΣfxΣf
Shortcut: x̄ = A + ΣfdΣf,   d = x − A
Continuous data → use mid-values x = (l + u)/2

Median (raw data)

Arrange in order →
n odd: value at position n+12
n even: mean of n2th and n2+1th

Median (grouped)

Median = l + N/2 − cfₚf × h
l = lower limit of median class, cfₚ = cf before it, f = its frequency, h = width

Mode

Modal class = highest frequency
Mode = l + f₁ − f₀2f₁ − f₀ − f₂ × h

Quartiles

Q₁ → N/4 · Q₂ = Median → N/2 · Q₃ → 3N/4
Inter-quartile range = Q₃ − Q₁
